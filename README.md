<h1>Three Sided Flashcards</h1>

Three Sided Flashcards is a Python desktop application for studying Chinese vocabulary through three connected components: Chinese characters, Pinyin (pronunciation) and English meanings. Unlike traditional two-sided flashcards, Three Sided Flashcards allows for more flexibility as users can choose which component to use as question and which component to use as answer. 

<b>Running the app:</b>

Download the repo, ensure that Python 3 and Tkinter are installed, run 
```python3 threeSidedFlashcards.py``` in terminal

A ```threeSidedFlashcards.json``` will be created by the app to store flashcard sets.

<b>How to use:</b>
1. Create a new flashcard set
2. Input a title and vocab entries
3. Return to menu and practice the flashcard sets
4. Select a set and choose a question type and answer type
5. Practice!
